# Arkedia Development (أركيديا للبرمجيات)

**Custom software studio, founded in 2022 by [Anas Amin](https://anasamin.dev).** Business systems on .NET for companies in Saudi Arabia, the Gulf and Egypt, delivered in Arabic and English.

We build multi-tenant SaaS, ERP and operations platforms, bilingual websites with admin portals, and Flutter apps.
